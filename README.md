\# 🚀 Full Stack Application (Angular + Spring Boot)



This project is a full-stack web application built by following a structured learning playlist on YouTube. It demonstrates how to design, develop, and deploy a modern web application using Angular (frontend) and Spring Boot (backend).



\---



\## 📚 Learning Source



\- YouTube Playlist: \[Watch Here](https://youtube.com/playlist?list=PLZTETldyguF2bRz-ypCa3a8gumxeXB4pu)



This project is based on step-by-step implementation from the playlist, covering real-world development practices.



\---



\## 🧠 Project Overview



The application showcases:



\- Frontend development using Angular

\- Backend REST API development using Spring Boot

\- Integration between frontend and backend

\- CRUD operations

\- Basic authentication \& validation



\---



\## 🏗️ Tech Stack



\### Frontend

\- Angular (v20)

\- TypeScript

\- SCSS

\- RxJS



\### Backend

\- Spring Boot

\- Java

\- Spring Data JPA

\- REST APIs



\### Database

\- MySQL



\---



\## ⚙️ Features



\- ✅ Create, Read, Update, Delete (CRUD)

\- ✅ REST API integration

\- ✅ Modular Angular architecture

\- ✅ Responsive UI

\- ✅ Authentication

\## 🚀 Getting Started



\### 🔧 Prerequisites



\- Node.js \& npm

\- Angular CLI

\- Java 17+

\- Maven / Gradle

\- Database (MySQL/PostgreSQL)



\---



\### ▶️ Run Frontend



```bash

cd frontend

npm install

ng serve



App will run at: http://localhost:4200



▶️ Run Backend

cd backend

./mvnw spring-boot:run



Backend runs at: http://localhost:9090
